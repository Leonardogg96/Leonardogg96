### ⚡ Power Green Monitoring

> Sistema criado para solucionar um problema real de operação de um eletroposto.

Aplicação em **Python** responsável por monitorar uma estação de recarga de veículos elétricos através de integração com API.

**Principais funcionalidades:**

* Monitoramento automático do status da estação
* Consulta periódica através de API
* Detecção de indisponibilidade e falhas
* Alertas em tempo real no celular
* Coleta de dados das sessões de carregamento
* Cálculo de faturamento diário
* Relatórios automáticos após a virada do dia
* Armazenamento local utilizando SQLite
* Controle de configurações e estados da aplicação

**Tecnologias:**

`Python` `REST API` `JSON` `SQLite` `HTTP` `ntfy` `Automação`
